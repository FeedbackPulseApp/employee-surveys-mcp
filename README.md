# FeedbackPulse Employee Surveys MCP

Public MCP server from [FeedbackPulse](https://feedbackpulse.com/) for designing employee surveys. Preview a survey, prepare it, and save it. No sign-in required.

## Endpoint

`https://app.feedbackpulse.com/mcp/employee-surveys` (streamable HTTP, no auth)

```bash
npx -y mcp-remote https://app.feedbackpulse.com/mcp/employee-surveys
```

## Tools

- `preview_survey`
- `prepare_survey_save`
- `save_survey`

For the full FeedbackPulse server (OAuth), see [FeedbackPulseApp/mcp](https://github.com/FeedbackPulseApp/mcp) and the [MCP docs](https://feedbackpulse.com/help/integrations/mcp-overview/).
